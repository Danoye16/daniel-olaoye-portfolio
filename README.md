# Daniel Olaoye — Vercel Portfolio

## 1. Upload to GitHub
1. Create a GitHub account if you do not already have one.
2. Create a new repository named `daniel-olaoye-portfolio`.
3. Upload the contents of this folder to the repository.
4. Commit the files.

## 2. Deploy to Vercel
1. Sign in to Vercel with GitHub.
2. Choose **Add New → Project**.
3. Import `daniel-olaoye-portfolio`.
4. Vercel should detect Next.js automatically.
5. Click **Deploy**.
6. Your site will receive a `vercel.app` address.

## 3. Personalize before publishing
- Replace `[Insert URL]` placeholders with your LinkedIn/portfolio details.
- Add your phone number.
- Replace the LinkedIn placeholder link in `app/page.js` with your real LinkedIn URL.
- Add a professional headshot later if desired.
- Keep demonstration case studies clearly labeled as demonstrations.

## 4. CV
Add the final public Vercel address to your CV as:
Portfolio: https://YOUR-VERCEL-DOMAIN.vercel.app
